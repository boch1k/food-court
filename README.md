# Food Court

Клиентское приложение для заказа еды на React, TypeScript и Vite. Интерфейс использует Tailwind CSS v4 и React Router. Заказы и сохранённые адреса хранятся в `localStorage` браузера отдельно для каждого пользователя.

## Развёртывание через Docker Compose

Требуются Docker Engine и Docker Compose v2.

```sh
docker compose up -d --build
```

Приложение будет доступно на порту `8080`. Настройте внешний reverse proxy или firewall, если нужен доступ из интернета; для HTTPS используйте TLS на внешнем proxy.

Полезные команды:

```sh
docker compose ps
docker compose logs -f frontend
docker compose down
```

Данные хранятся в браузере и доступны только в том браузере и профиле, где были созданы. Очистка данных сайта удалит заказы и адреса этого браузера.

## Локальная разработка

Требуются Node.js и pnpm. Установите зависимости и запустите Vite:

```sh
pnpm install --frozen-lockfile
pnpm dev
```

Для production-сборки и проверки типов:

```sh
pnpm run build
```

## Структура приложения

- `src/pages` — страницы и маршруты.
- `src/components` — переиспользуемые компоненты интерфейса.
- `src/context` — состояние авторизации, корзины и модальных окон.
- `src/hooks` — хуки для локального состояния и хранилища.
- `src/utils/localData.ts` — чтение и запись заказов и адресов в `localStorage`.
- `src/utils/mockProducts.ts` — демонстрационные товары.

Авторизация в демонстрационной версии выполняется по номеру телефона с фиксированным кодом `1111`; она не заменяет серверную аутентификацию.
